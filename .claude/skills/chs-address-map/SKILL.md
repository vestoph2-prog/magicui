# Адресная разметка ЧС по скриншоту Яндекс Карт

Яндекс Карты недоступны из облака (блокировка и нужен API-ключ), поэтому
номера домов берутся **со скриншота пользователя**, а координаты получаются
привязкой скриншота к полигону из GeoJSON.

## Что нужно от пользователя
1. GeoJSON зоны (полигон, нарисованный в Конструкторе карт Яндекса).
2. Скриншот из Конструктора/Яндекс Карт, на котором **виден весь красный
   контур этого полигона** и подписи номеров домов. Масштаб — такой, чтобы
   номера читались. Если контур на скриншоте обрезан — попроси переснять.
3. (Необязательно) название зоны/улицы; иначе берётся `metadata.name` из GeoJSON.

## Порядок работы
Скрипт: `scripts/chs_map.py` (рядом с этим файлом). Зависимости:
`pip install numpy pillow xlrd xlwt xlutils`. Рабочую папку `OUT` создавай
во временной/рабочей директории, итоговые файлы отдай пользователю.

### 1. Привязка и поиск зданий
```
python3 scripts/chs_map.py detect ZONE.geojson SCREEN.png --out OUT
```
Печатает невязку привязки (норма — до 2–3 px) и число найденных зданий.
Создаёт `OUT/detect.json` и `OUT/detect_preview.png`: синяя линия — полигон
после привязки, синие рамки с номерами — найденные здания.

**Обязательно открой `detect_preview.png` (Read) и проверь:**
- синяя линия легла на красный контур (иначе — скриншот не тот/контур
  перекрыт; сообщи пользователю);
- рамки стоят на зданиях. Мусор (тротуары, площадки, надписи) пропиши в
  `ignore_buildings`; пропущенные здания — в `extra_buildings` (`x`,`y` в px).

### 2. Подписи домов
Посмотри исходный скриншот и превью, составь `OUT/labels.json`:
```json
{
  "name": "ул. Дедюхина ЧС Нягань",
  "street": "Дедюхина",
  "labels": [
    {"text": "1",   "building": 4},
    {"text": "8А",  "building": 15},
    {"text": "10А", "building": 15},
    {"text": "16А", "x": 1351, "y": 644},
    {"text": "3", "building": 7, "street": "Загородных"}
  ],
  "ignore_buildings": [48],
  "extra_buildings": [{"x": 900, "y": 600}]
}
```
- `building` — номер рамки из превью, на которой стоит подпись (надёжнее всего).
- Если под подписью здание не нашлось — дай `x`,`y` подписи в пикселях
  исходного скриншота.
- Две подписи на одной рамке (сдвоенный дом) — укажи один `building` обоим,
  скрипт разведёт точки по половинкам здания.
- `street` у подписи — если дом по другой улице, чем общий `street`.
- Номер переписывай точно как на карте (кириллическая «А», дроби `10/1`).
- **Здания без номера не подписывай** — они автоматически станут жёлтыми «?».

### 3. Сборка
```
python3 scripts/chs_map.py build --out OUT --labels OUT/labels.json
```
Результат в `OUT`:
- `<name>.geojson` — полигон зоны + зелёные метки «ул. X, д. N» (#1bad03) +
  жёлтые «?» (#ffd21e) «строение без номера — уточнить». Импортируется в
  Конструктор карт Яндекса (Импорт → GeoJSON).
- `АП ЧС <name>.xls` — **пустой** костяк таблицы адресной программы (шапка
  97 колонок по образцу «АП ЧС, вторичка», без данных).
- `result_preview.png` — контроль: открой его (Read) и сверь, что зелёные
  точки стоят на своих домах.

Отдельно пустая таблица: `python3 scripts/chs_map.py skeleton OUT/table.xls --title "..."`.

### 4. Ответ пользователю
Отдай GeoJSON и .xls (и превью при необходимости). Коротко: сколько домов
с номером, сколько жёлтых, какие подписи без здания под ними, что
проверить (жёлтые могут быть как хозпостройками, так и жилыми домами без
подписи — пользователь поправит сам). Номера домов не придумывай.
