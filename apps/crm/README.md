# CRM задач по сделкам и объектам — Telegram Mini App

Задачи от заказчика по сделкам на разных объектах. Всё внутри Telegram:
приложение открывается кнопкой в боте, уведомления приходят в чат бота.

**Сущности:** Объект → Сделки → Задачи → Комментарии и история изменений.

## Роли

| Роль | Что может |
| --- | --- |
| Администратор | всё + роли пользователей, удаление, приглашение менеджеров |
| Менеджер | объекты, сделки, задачи, исполнители, статусы, приглашение заказчика |
| Заказчик | видит все объекты/сделки/задачи, ставит задачи, комментирует, **принимает работу или возвращает на доработку**, отменяет свою заявку |

Первый, кто откроет приложение, становится администратором (или задайте
`ADMIN_IDS`). Остальных зовите одноразовыми ссылками: вкладка «Команда» →
«Создать ссылку» → «Отправить в Telegram».

## Жизненный цикл задачи

`Новая → В работе → На проверке → Готово` (+ `Отменена`). Когда менеджер
переводит задачу «На проверку», заказчик получает уведомление и в один клик
принимает работу или возвращает её. Все изменения пишутся в историю задачи,
а остальные участники получают сообщение от бота с кнопкой «Открыть CRM».

## Запуск

Сервер — Node.js ≥ 22.18 без внешних зависимостей (встроенный `node:sqlite`),
фронтенд — React + Vite.

```bash
cp .env.example .env    # впишите BOT_TOKEN и WEBAPP_URL
pnpm install
pnpm build              # собирает фронтенд в dist/
pnpm start              # API + статика + бот на :3000
```

Нужен публичный **HTTPS**-адрес (Telegram открывает Mini App только по HTTPS):
VPS + nginx/Caddy, Render, Railway, Fly.io и т.п. Пропишите его в
`WEBAPP_URL` — при старте бот сам поставит кнопку меню «CRM».

### Docker

```bash
docker build -t crm apps/crm
docker run -d --name crm -p 3000:3000 -v crm-data:/data \
  -e BOT_TOKEN=... -e WEBAPP_URL=https://crm.example.com crm
```

База — один файл SQLite в `/data/crm.db`; для бэкапа достаточно копировать его.

### Опционально: Mini App в @BotFather

`/newapp` → укажите `WEBAPP_URL`, придумайте короткое имя и пропишите его в
`APP_SHORT_NAME`. Тогда ссылки-приглашения будут открывать приложение сразу
(`t.me/<бот>/<app>?startapp=…`), а не через чат с ботом.

## Локальная разработка

```bash
pnpm dev:api            # API на :3000 с DEV_AUTH=1
pnpm dev:web            # Vite на :5173, проксирует /api
```

Вне Telegram откройте `http://localhost:5173/?dev=2:Мария` — так можно
зайти под любым пользователем. Никогда не включайте `DEV_AUTH` в продакшене.

## Безопасность

- Каждый запрос подписан `initData` Telegram; сервер проверяет HMAC токеном бота
  и срок жизни подписи (`AUTH_MAX_AGE`, по умолчанию 24 ч).
- Токен бота хранится только в `.env` / переменных окружения, не в репозитории.
